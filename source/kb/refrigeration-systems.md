# 制冷与热泵系统

制冷系统是将制冷设备按特定流程组合而成的整体。本章涵盖蒸汽压缩式制冷系统、热泵系统和吸收式制冷三大类型。

---

## 一、蒸汽压缩式制冷系统

### 1.1 基本系统流程

**四大件连接**：压缩机 → 冷凝器 → 膨胀阀 → 蒸发器 → 压缩机（制冷剂在系统内循环）。

**典型冷水机组系统**：在四大件基础上，加冷却水循环（冷却塔）和冷冻水循环（空调末端）。

### 1.2 系统类型

| 系统类型 | 特点 | 应用 |
|----------|------|------|
| 单元式空调 | 一体机，即插即用 | 家用、小型商用 |
| 多联机(VRF) | 一拖多，独立控制 | 商业建筑 |
| 冷水机组 | 集中供冷，输配灵活 | 大型建筑 |
| 模块化冷水机 | 多模块组合，冗余 | 中大型项目 |

### 1.3 冷水机组系统

**水冷式冷水机组**：
- 制冷量范围：100～5000 kW
- COP：4.5～6.5（满负荷）
- IPLV：6.0～9.0（综合部分负荷效率）

**风冷式冷水机组**：
- 制冷量范围：30～1500 kW
- COP：2.5～3.5
- 无需冷却水，安装简便

**部分负荷性能**：

| 负荷率 | 典型COP | 运行策略 |
|--------|---------|----------|
| 100% | 基准 | 满负荷运行 |
| 75% | 105～110% | 变频调节 |
| 50% | 100～110% | 最优效率区 |
| 25% | 80～90% | 避免低负荷 |

## 二、热泵系统

### 2.1 热泵原理

**本质**：可逆运行的制冷系统，冬季从低温热源吸热，向室内供热。

**性能系数**：
$$COP_{heating} = \frac{Q_h}{W} = COP_{cooling} + 1$$

### 2.2 空气源热泵

**工作原理**：从室外空气中吸热（即使-15°C也能工作）。

**关键问题**：

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 结霜 | 蒸发温度低于0°C | 逆循环除霜、热气旁通 |
| 低温衰减 | 吸气比容增大 | 喷气增焓、变频 |
| 噪声 | 室外机风机 | 低噪声设计、隔声 |

**适用条件**：
- 冬季室外温度 > -15°C
- 夏热冬冷地区最佳

### 2.3 水源热泵

**类型**：

| 类型 | 热源 | 特点 |
|------|------|------|
| 地下水 | 井水 | 温度稳定(15～18°C)，效率高 |
| 地表水 | 湖水、河水 | 需考虑水质和结冰 |
| 再生水 | 污水、中水 | 变废为宝，需处理 |

**系统形式**：
- **开式系统**：直接取水，需水处理
- **闭式系统**：换热器隔离，维护简单

### 2.4 地源热泵

**类型**：

| 类型 | 换热器形式 | 适用条件 |
|------|------------|----------|
| 垂直埋管 | 钻孔埋管(50～150m) | 场地有限 |
| 水平埋管 | 浅埋(1～2m) | 场地充裕 |
| 桩基埋管 | 与建筑桩基结合 | 新建建筑 |

**设计要点**：
- 土壤热平衡：全年冷热负荷应平衡
- 钻孔间距：4～6m
- 埋管深度：根据地质条件

**性能**：
- 冬季COP：3.5～4.5
- 夏季COP：5.0～6.0

### 2.5 热泵热水器

**类型**：
- 空气源热泵热水器
- CO₂跨临界热泵热水器（高温出水）

**特点**：
- 能效比电热水器高3～4倍
- 出水温度：55～90°C（CO₂系统）

## 三、吸收式制冷

### 3.1 工作原理

**驱动力**：热能（蒸汽、热水、燃气、废热）

**工质对**：
- 溴化锂-水（LiBr-H₂O）：制冷温度 > 0°C
- 氨-水（NH₃-H₂O）：制冷温度可达 -60°C

**基本循环**：发生器 → 冷凝器 → 膨胀阀 → 蒸发器 → 吸收器 → 溶液泵 → 发生器。与压缩式区别：用**热能驱动的发生-吸收过程**替代电能驱动的压缩机。

### 3.2 溴化锂吸收式冷水机组

**单效机组**：
- 驱动热源：80～120°C热水或低压蒸汽
- COP：0.6～0.8

**双效机组**：
- 驱动热源：≥0.4 MPa蒸汽或燃气
- COP：1.0～1.3

**直燃型**：
- 燃料：天然气、柴油
- 一机三用：制冷、采暖、生活热水

**性能对比**：

| 类型 | 驱动能源 | COP | 适用场景 |
|------|----------|-----|----------|
| 单效 | 废热、太阳能 | 0.7 | 有余热场合 |
| 双效 | 蒸汽、燃气 | 1.2 | 区域供冷 |
| 直燃 | 燃气 | 1.1 | 无蒸汽源 |

### 3.3 吸收式 vs 压缩式

| 对比项 | 吸收式 | 压缩式 |
|--------|--------|--------|
| 驱动能源 | 热能 | 电能 |
| COP | 0.7～1.3 | 3～6 |
| 一次能源效率 | 相当（余热时更优） | - |
| 运动部件 | 少（仅溶液泵） | 多 |
| 维护 | 简单 | 较复杂 |
| 初投资 | 高 | 较低 |
| 适用 | 有余热、峰谷电价差大 | 一般场合 |

## 四、系统设计与选型

### 4.1 负荷计算

**冷负荷组成**：
- 围护结构传热
- 太阳辐射
- 人员散热
- 设备散热
- 新风负荷

**负荷指标**：

| 建筑类型 | 冷负荷指标(W/m²) |
|----------|------------------|
| 办公楼 | 80～120 |
| 商场 | 150～250 |
| 酒店 | 100～150 |
| 医院 | 120～180 |

### 4.2 系统选型原则

| 条件 | 推荐系统 |
|------|----------|
| 小型建筑(<500m²) | 分体空调、多联机 |
| 中型建筑(500～5000m²) | 多联机、风冷冷水机 |
| 大型建筑(>5000m²) | 水冷冷水机+锅炉/热泵 |
| 有余热/燃气 | 吸收式冷水机 |
| 环保要求高 | 地源热泵 |
| 夏热冬冷 | 空气源热泵 |

### 4.3 能效标准

**中国能效标识**：

| 等级 | IPLV(C) | 说明 |
|------|---------|------|
| 1级 | ≥7.2 | 先进水平 |
| 2级 | ≥6.3 | 节能水平 |
| 3级 | ≥5.4 | 准入水平 |
