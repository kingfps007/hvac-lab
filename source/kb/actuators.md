执行器是控制回路的"手脚"。本知识库覆盖暖通空调系统中最常用的电动调节阀、风阀执行器、变频器等执行机构的类型、选型参数与工程应用注意事项。

## 1. 电动调节阀（Control Valve）

调节阀是暖通水系统最重要的执行器，用于连续调节冷/热水流量以控制温度。

### 1.1 控制阀流量特性

| 特性 | 说明 |
|------|------|
| **等百分比特性(EP)** | 行程与流量成对数关系。小开度时流量变化小，大开度时变化大。与换热器非线性互补，暖通主流选择 |
| **线性特性(LIN)** | 行程与流量成正比。适用于压差恒定的系统 |
| **快开特性(QO)** | 小开度即大流量，用于ON/OFF控制 |

### 1.2 阀权度（Valve Authority）

| 项目 | 说明 |
|------|------|
| **定义** | N = ΔPv_全开 / ΔPs_总 = 阀门全开时压降 ÷ 系统总压降 |
| **推荐值** | N = 0.3～0.5（理想0.5）。N<0.25时等百分比特性退化为快开，控制品质恶化 |
| **工程对策** | 阀门Kvs选型时满足ΔPv≥0.3×ΔPs; 必要时加装自力式压差控制器 |

### 1.3 Kvs值与选型

| 项目 | 说明 |
|------|------|
| **Kvs定义** | 阀门全开、两端压差=1bar时通过的水流量(m³/h) |
| **计算公式** | Kv = Q / √ΔPv，其中Q=流量(m³/h)、ΔPv=阀门压降(bar) |
| **选型原则** | 计算Kv值后选大一档标准Kvs，确保最大工况阀门开度≤85% |

### 1.4 常见阀体类型

| 类型 | 说明 |
|------|------|
| **截止阀(Globe)** | 调节性好、等百分比特性、压降较大，DN15~DN300。暖通水阀首选 |
| **球阀(Segmented Ball)** | V型球阀，等百分比特性、大通径、高压差适用 |
| **蝶阀(Butterfly)** | 近似等百分比、低压降、大口径(DN250+)、开关为主 |
| **座阀(ZONE Valve)** | 小口径DN15~DN25，风机盘管/散热器末端用，ON/OFF或三浮点控制 |

> 参考文献: *Belimo, "Hydronic Reference Guide", 2023; ASHRAE Handbook HVAC Systems & Equipment (2020)*

## 2. 风阀执行器（Damper Actuator）

### 选型参数与技术指标

| 参数 | 说明 |
|------|------|
| **扭矩(Nm)** | ≤0.5m²→5Nm; 0.5～1m²→10Nm; 1～2m²→20Nm; ≥2m²→40Nm |
| **控制信号** | 开关型(ON/OFF); 三浮点(3-point floating); 调节型(0-10V / 2-10V / 4-20mA) |
| **旋转角度** | 90°(标准); 180°(特殊); 机械限位可调 |
| **运行时间** | 标准150s/90°; 快速30s/90°; 慢速300s/90° |
| **反馈信号** | 0-10V位置反馈(电位器/霍尔); 两限位开关(全开/全关) |
| **弹簧复位** | 断电自动关闭/开启——用于消防排烟、防冻保护 |
| **防护等级** | IP54(室内); IP66(室外/高湿) |

### 暖通应用场景

| 场景 | 说明 |
|------|------|
| **新风阀** | 调节型，0-10V控制，根据CO₂/时间表调节新风量 |
| **回风阀** | 调节型，与新风阀反向联动 |
| **排风阀** | 开关型/调节型，排风控制 |
| **防烟防火阀** | 弹簧复位(断电关)，70°C/280°C熔断连锁关闭 |

## 3. 变频驱动（VFD / VSD）

### 暖通风机水泵变频控制

| 项目 | 说明 |
|------|------|
| **工作原理** | 交-直-交变频：AC输入→整流→直流母线→IGBT逆变→变频变压输出 |
| **节能原理** | 离心泵/风机相似定律：Q₂/Q₁=n₂/n₁, H₂/H₁=(n₂/n₁)², P₂/P₁=(n₂/n₁)³。转速降至80%，功率降至51% |
| **控制方式** | V/f恒压频比(风机泵类); 矢量控制(高精度); DTC直接转矩控制 |
| **暖通接口** | DDC AO(0-10V/4-20mA)→VFD频率指令; VFD运行/故障状态→DDC DI |
| **通信** | MODBUS RTU / BACnet MS/TP / PROFIBUS |
| **典型应用** | AHU送风机/回风机、冷却塔风机、冷冻水泵、冷却水泵 |
| **谐波治理** | 内置直流电抗器(3%阻抗); 有源前端(AFE)用于大功率 |

> 参考文献: *ABB, "Technical Guide No.4: Guide to Variable Speed Drives", 2022*

## 4. 执行器控制信号类型速查

| 信号类型 | 信号范围 | 优点 | 缺点 | 典型应用 |
|---------|---------|------|------|---------|
| 0-10V DC | 0～10V | 接线简单、可并联 | 压降限制距离(~30m) | 风阀执行器、小型调节阀 |
| 2-10V DC | 2～10V | 断线检测(0V=故障) | 同上 | 关键调节回路 |
| 4-20mA | 4～20mA | 抗干扰强、远传(>100m) | 需电流环接口 | 远程调节阀、现场仪表 |
| 三浮点 | 开/关/停(三线) | 断电保持位置、成本低 | 无位置反馈 | 风机盘管阀、散热器阀 |
| PWM | 占空比0-100% | DDC DO直接驱动 | 需热执行器(慢响应) | 电热阀、小型水阀 |
