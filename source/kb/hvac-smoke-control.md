# 防排烟

防排烟通过控制烟气蔓延、保障疏散通道安全，是建筑消防的重要组成部分。

---

## 一、火灾烟气特性

### 1.1 烟气组成

- **固体微粒**：炭黑、焦油颗粒（黑烟）
- **有毒气体**：CO、HCN、SO₂、NOₓ
- **高温气体**：200～800℃
- **水蒸气**

### 1.2 烟气危害

| 危害 | 说明 |
|------|------|
| **高温灼伤** | 上部烟气 600℃+ |
| **缺氧** | O₂ 浓度降至 10% 以下 |
| **毒气** | CO 中毒（致死最快） |
| **遮光** | 烟气浓度高，疏散困难 |

### 1.3 烟气流动规律

- **烟羽流**：火源上方，浮力驱动上升
- **顶棚射流**：撞击顶棚后水平扩散
- **烟气充填**：从顶部向下累积，形成**烟层**

烟气运动路径：火源 → 热羽流 → 撞击顶棚 → 顶棚射流向四周扩散 → 回降到烟层界面 → 沉降进入工作区。

> **关键参数**：
> - **烟层界面高度**：人员疏散的最低安全高度（≥ 1.8～2.0 m）
> - **烟气温度**：影响结构安全
> - **烟气浓度**：影响可见度

---

## 二、防烟分区

### 2.1 分区原则

- **防烟分区**面积 ≤ 500 m²（一般建筑）
- **净高 > 6m** 可达 1000 m²
- 用**挡烟垂壁**、**梁**或**隔墙**分隔
- 垂壁下垂高度 ≥ 0.5 m（仓库 0.8 m）

### 2.2 挡烟设施

| 类型 | 适用 |
|------|------|
| 固定挡烟垂壁 | 永久分隔 |
| 活动挡烟垂壁 | 平时隐蔽，火灾时自动落下 |
| 防火卷帘 | 大空间分隔 |
| 梁（高 ≥ 0.5 m） | 结构性分隔 |

## 三、自然排烟

### 3.1 原理

利用**热压 + 风压**作用，烟气从**上部开口**自然排出。

### 3.2 设置要求

| 部位 | 条件 |
|------|------|
| **可开启外窗** | 面积 ≥ 2% 防烟分区面积 |
| **高位窗口** | 下沿距顶棚 ≤ 0.5 m |
| **自动开启** | 与火灾报警联动 |

### 3.3 优缺点

| 优点 | 缺点 |
|------|------|
| 无动力、节能 | 受室外风影响大 |
| 构造简单 | 排烟不稳定 |
| 不占机房 | 不适合超高层 |

### 3.4 适用

- 建筑高度 ≤ 50m
- 中庭面积适中
- 自然通风条件好

---

## 四、机械排烟

### 4.1 系统组成

防烟分区 → 排烟口 → 排烟风机 → 室外；同时设补风口。

- **排烟口**：设于防烟分区内，距顶棚 ≤ 0.5 m
- **排烟风机**：专用，耐高温 280℃ 持续 30min
- **排烟风管**：钢板厚度加大，防火包裹
- **补风口**：风量 ≥ 排烟量 50%

### 4.2 排烟量

- **最小排烟量**：6 m³/(m²·min) × 防烟分区面积
- **中庭**：按 6 次/h 换气或 400000 m³/h
- **走道**：1 m² 排烟口排烟量 ≥ 60 m³/h

### 4.3 排烟口

- **常闭型**：火灾时电动或手动开启
- **常开型**：低层或长期通风部位
- **远控操作**：距地 1.3～1.5 m

## 五、加压送风（防烟）

### 5.1 原理

在疏散楼梯间、前室、避难层**加压送风**，形成**正压**，阻止烟气进入。

### 5.2 部位

- 防烟楼梯间及其前室
- 消防电梯前室
- 避难层
- 封闭楼梯间

### 5.3 压力要求

| 部位 | 余压值 |
|------|-------|
| 前室/合用前室 | 25～30 Pa |
| 楼梯间 | 40～50 Pa |
| 避难层 | ≥ 25 Pa |

> **压力过大的问题**：开门困难。**最大 ≤ 50 Pa**（消防队员可推开）。

### 5.4 送风量

按**门缝漏风量**计算：
- 楼梯间：每秒 1 门开启 1 m 缝宽的漏风量
- 简化：按 0.7～1.0 m/s 门缝流速反算

### 5.5 正压送风口

- **楼梯间**：每 2～3 层设一个常闭风口
- **前室**：每层一个
- 火灾时联动开启

---

## 六、机械排烟 vs 加压送风

| 维度 | 机械排烟 | 加压送风 |
|------|---------|---------|
| 部位 | 起火房间/防烟分区 | 疏散通道/前室 |
| 目的 | 排走烟气 | 阻止烟气进入 |
| 风机 | 排烟风机（耐高温） | 送风机 |
| 联动 | 火灾信号 | 火灾信号 |
| 风口 | 大流量排烟口 | 多点送风口 |
