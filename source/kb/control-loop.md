建筑自动化系统的核心是控制回路（Control Loop）。本知识库系统梳理反馈控制、前馈控制、串级控制等经典回路架构，以及在暖通空调（HVAC）系统中的DDC控制回路设计实践。

## 1. 反馈控制回路（Feedback Control Loop）

反馈控制是暖通自控中最基础的回路形式。控制器比较设定值(SP)与传感器实测值(PV)，根据偏差(e = SP - PV)计算控制输出(OP)，驱动执行器调节被控对象，使PV趋近SP。

### 反馈回路架构与组成

| 项目 | 说明 |
|------|------|
| **组成要素** | 传感器 → 控制器(DDC) → 执行器 → 被控对象 → 传感器（闭环） |
| **典型暖通场景** | 空调机组(AHU)送风温度控制：温度传感器测量送风温度 → DDC PID运算 → 调节冷水阀/热水阀开度 → 送风温度变化 → 再次测量 |
| **关键参数** | 比例增益Kp、积分时间Ti、微分时间Td、采样周期Ts |
| **优点** | 结构简单、鲁棒性强、不依赖精确数学模型 |
| **局限** | 只能"事后"纠正，对大滞后系统响应慢 |

> 参考文献：*ASHRAE Handbook—HVAC Applications, Chapter 47: Design and Application of Controls (2023)*

## 2. 前馈控制回路（Feedforward Control）

前馈控制在扰动影响被控变量之前，先测量扰动量并提前调整控制输出。"预测+预防"，而非"测量+纠正"。

### 前馈控制原理与暖通应用

| 项目 | 说明 |
|------|------|
| **工作原理** | 测量可测扰动(如室外温度、太阳辐照) → 前馈控制器计算补偿量 → 叠加到控制输出 |
| **典型场景** | AHU送风温度前馈补偿：根据室外气温变化提前调节冷/热水量，避免室内温度波动 |
| **前馈模型** | 常采用稳态能量平衡模型：Q_req = ṁ × cp × (T_set - T_OA) |
| **与反馈配合** | 前馈+反馈复合控制：前馈快速响应扰动，反馈消除稳态误差 |

> 参考文献：*Seborg, D.E. et al., "Process Dynamics and Control", 4th Ed., Wiley (2016), Chapter 15*

## 3. 串级控制回路（Cascade Control）

串级控制使用两个嵌套的PID回路：主回路（外环）控制主要被控变量，副回路（内环）控制中间变量。内环响应速度远快于外环，能有效抑制进入内环的扰动。

### 串级回路结构与暖通实例

| 项目 | 说明 |
|------|------|
| **结构** | 主控制器(SP1,PV1) → 输出作为副控制器SP → 副控制器(SP2,PV2) → 执行器 → 副对象 → 主对象 |
| **典型场景1** | AHU送风温度串级：主回路=房间温度 → 副回路=送风温度 → 水阀 |
| **典型场景2** | 换热器出口温度串级：主回路=二次侧出水温度 → 副回路=一次侧蒸汽流量/阀门开度 |
| **参数整定原则** | 先整定内环(快速)，再整定外环(缓慢)；内环采样周期为外环的1/3～1/5 |
| **优势** | 内环可快速抑制二次扰动，显著改善大惯性系统的控制品质 |

> 参考文献：*王树青等,《工业过程控制工程》, 化学工业出版社 (2014), 第6章*

## 4. DDC（直接数字控制）控制器

DDC是楼宇自控系统的核心控制单元。以微处理器为基础，直接采集传感器信号，执行控制算法，输出控制信号。一台DDC可同时管理多个控制回路。

### DDC回路配置参数

| 项目 | 参数 |
|------|------|
| **AI输入** | 4-20mA / 0-10V / NTC 10K / PT1000，典型8-16通道 |
| **AO输出** | 0-10V / 4-20mA，驱动调节阀/风阀执行器，典型4-8通道 |
| **DI输入** | 干接点，用于状态反馈、报警、启停信号 |
| **DO输出** | 继电器输出(AC 250V/3A)，控制启停、开关阀 |
| **控制算法** | PID、ON/OFF、时间比例、序列控制等 |
| **通信接口** | BACnet MS/TP、MODBUS RTU/TCP、LonWorks |

> 参考文献：*ASHRAE Standard 135-2020: BACnet*

## 5. 暖通典型控制回路速查表

| 被控对象 | 控制目标 | 传感器 | 执行器 | 推荐控制方式 |
|---------|---------|-------|-------|------------|
| AHU送风温度 | 送风温度稳定在设定值 | 风道温度传感器 | 冷/热水调节阀 | PID / 串级(外环室温) |
| 房间温度 | 室内温度舒适(±1°C) | 室内温控器 | 风机盘管水阀 / VAV风阀 | PID / ON-OFF |
| 冷机出水温度 | 冷冻水供水温度恒定 | 浸入式温度传感器 | 压缩机导叶/滑阀 | PID |
| 换热器二次出水 | 二次侧出水温度 | 管壁/浸入式温度传感器 | 一次侧蒸汽/热水调节阀 | 串级PID |
| 空调区域静压 | 最不利末端静压满足要求 | 风管静压传感器 | 风机变频器(VFD) | PI控制 |
| 新风量 | CO₂浓度<1000ppm | CO₂传感器(NDIR) | 新风阀执行器 | 需求控制通风(DCV) |
