# 制冷剂与工质

制冷剂是制冷系统中完成能量传递的工作介质，其热力学性质直接决定系统性能。本章涵盖制冷剂、载冷剂和润滑油三大类工质。

---

## 一、制冷剂

### 1.1 制冷剂编号规则（ASHRAE Standard 34）

| 类型 | 编号规则 | 示例 |
|------|----------|------|
| 卤代烃 | R + 百位数(碳-1) + 十位数(氢+1) + 个位数(氟) | R22 (CHClF₂) |
| 碳氢化合物 | R + 碳原子数 + 氢原子数 | R290 (C₃H₈) |
| 无机化合物 | R7 + 分子量整数 | R717 (NH₃, M=17) |
| 混合物 | R4xx（共沸）/ R5xx（非共沸） | R410A, R407C |

### 1.2 常用制冷剂特性

| 制冷剂 | 类型 | ODP | GWP | 主要应用 | 替代趋势 |
|--------|------|-----|-----|----------|----------|
| R22 | HCFC | 0.055 | 1810 | 空调、冷冻 | 逐步淘汰 |
| R410A | HFC混合 | 0 | 2088 | 家用空调 | 向R32过渡 |
| R32 | HFC | 0 | 675 | 变频空调 | 主流替代 |
| R134a | HFC | 0 | 1430 | 汽车空调、冷水机 | 向R1234yf过渡 |
| R290 | 碳氢 | 0 | 3 | 家用冰箱 | 可燃性限制 |
| R717 | 无机 | 0 | 0 | 工业制冷 | 大型系统 |
| CO₂ (R744) | 无机 | 0 | 1 | 跨临界循环 | 热泵、超市 |

> **ODP**：臭氧消耗潜能值；**GWP**：全球变暖潜能值（以CO₂为基准，100年）

### 1.3 制冷剂热力学性质要求

**理想制冷剂应具备的性质**：

| 类别 | 要求 | 原因 |
|------|------|------|
| 热力学 | 临界温度高，蒸发潜热大 | 适应宽温区，减小设备尺寸 |
| 物理 | 粘度低，导热系数高 | 减小流动阻力，强化传热 |
| 化学 | 化学稳定性好，不腐蚀金属 | 系统安全可靠 |
| 安全 | 无毒、不可燃或低可燃 | 人身安全 |
| 环保 | ODP=0, GWP低 | 环境保护 |

### 1.4 制冷剂替代趋势

- **1987 蒙特利尔议定书**：CFCs（CFC-11、CFC-12）淘汰开始
- **1990s**：HCFCs 过渡使用，R22 广泛应用
- **2010s**：HFCs 普及，R410A、R134a 主导
- **2020s**：HFCs 削减（基加利修正案）
- **未来**：天然制冷剂（R290、R717、CO₂）回归

## 二、载冷剂

### 2.1 载冷剂的作用与选择

载冷剂是在间接制冷系统中传递冷量的中间介质，用于：
- 远距离输送冷量
- 集中供冷系统
- 需要精确控温的场合

### 2.2 常用载冷剂特性

| 载冷剂 | 凝固点 | 使用温度 | 特点 | 应用 |
|--------|--------|----------|------|------|
| 水 | 0°C | > 0°C | 比热大，成本低 | 空调系统 |
| 乙二醇水溶液 | -15~-50°C | -10~-40°C | 腐蚀性需抑制 | 冰蓄冷、低温 |
| 丙二醇水溶液 | -15~-50°C | -10~-40°C | 低毒，食品级 | 食品加工 |
| 氯化钙盐水 | -20~-55°C | -15~-45°C | 成本低，腐蚀性强 | 工业制冷 |
| 硅油 | -80°C | -70～150°C | 宽温区，粘度大 | 特殊场合 |

### 2.3 载冷剂浓度与凝固点

**乙二醇水溶液**：

| 质量浓度 | 体积浓度 | 凝固点 | 比热(20°C) |
|----------|----------|--------|------------|
| 20% | 18.8% | -8°C | 3.89 kJ/(kg·K) |
| 30% | 28.4% | -15°C | 3.56 kJ/(kg·K) |
| 40% | 38.4% | -25°C | 3.20 kJ/(kg·K) |
| 50% | 48.6% | -35°C | 2.84 kJ/(kg·K) |

> **注意**：浓度并非越高越好，需综合考虑凝固点、粘度、比热和流动性。

## 三、润滑油

### 3.1 润滑油的功能

| 功能 | 说明 |
|------|------|
| 润滑 | 减少摩擦副磨损 |
| 冷却 | 带走摩擦热和压缩热 |
| 密封 | 提高压缩机容积效率 |
| 降噪 | 降低机械噪声 |
| 清洁 | 带走磨损颗粒 |

### 3.2 润滑油类型

| 类型 | 基础油 | 特点 | 适用制冷剂 |
|------|--------|------|------------|
| 矿物油 | 环烷基/石蜡基 | 成本低，与R22相容 | R22 |
| 烷基苯(AB) | 合成烃 | 低温流动性好 | R22, R502 |
| 聚酯油(POE) | 合成酯 | 吸湿性强，与HFC相容 | R134a, R410A |
| 聚醚油(PAG) | 聚醚 | 与R134a完全相溶 | 汽车空调 |

### 3.3 润滑油与制冷剂的相容性

**关键问题**：润滑油必须能与制冷剂在运行温度范围内充分相溶。

| 制冷剂 | 推荐润滑油 | 相容性特点 |
|--------|------------|------------|
| R22 | 矿物油、AB | 高温相溶，低温分层 |
| R134a | POE、PAG | 完全相溶 |
| R410A | POE | 必须合成油 |
| R290 | 矿物油 | 与烃类自然相溶 |
| CO₂ | 专用POE | 跨临界工况特殊要求 |

### 3.4 润滑油管理要点

1. **充注量**：过多导致换热恶化，过少润滑不足
2. **回油设计**：保证压缩机回油，防止积存在蒸发器
3. **吸湿性**：POE油易吸湿，需严格密封
4. **更换周期**：根据运行时间和油质检测确定

## 四、工质选择速查表

| 应用场景 | 制冷剂 | 载冷剂 | 润滑油 |
|----------|--------|--------|--------|
| 家用分体空调 | R32 | - | POE |
| 多联机 | R410A | - | POE |
| 冷水机组 | R134a | 水 | POE |
| 工业冷冻 | R717 | 盐水/乙二醇 | 矿物油 |
| 跨临界CO₂热泵 | R744 | 水 | 专用POE |
| 冰蓄冷系统 | R410A | 乙二醇溶液 | POE |
