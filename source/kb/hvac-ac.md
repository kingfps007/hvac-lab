# 空气调节

空气调节是 HVAC 的**核心内容**。本章涉及大量**焓湿图分析**和**系统设计**，从湿空气性质出发，逐步深入到定风量、变风量、风机盘管和多联机系统。

## 一、湿空气的物理性质

### 1.1 基本参数

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 干球温度 | $t$ | ℃ | 实际空气温度 |
| 湿球温度 | $t_s$ | ℃ | 反映含湿能力 |
| 露点温度 | $t_l$ | ℃ | 等压冷却到饱和 |
| 相对湿度 | $\varphi$ | % | 实际含湿/饱和含湿 |
| 含湿量 | $d$ | g/kg 干空气 | 实际水汽量 |
| 焓 | $h$ | kJ/kg 干空气 | 显热+潜热总和 |
| 密度 | $\rho$ | kg/m³ | 约 1.2（标态） |
| 比容 | $v$ | m³/kg | 1/ρ |

### 1.2 焓湿图（h-d 图）

**结构与要素**：
- 横轴为含湿量 $d$，纵轴为焓 $h$
- **等温线 $t$**：近似直线，斜率大
- **等湿线 $d$**：垂直线
- **等焓线 $h$**：水平线
- **等相对湿度线 $\varphi$**：曲线簇，$\varphi = 100\%$ 为饱和线
- **水蒸气分压力线 $p$**：辅助读图

> **读图技巧**：焓湿图上"沿等湿线向上"是加热（焓增 d 不变），"斜向左下"是冷却去湿（焓降 d 降），"斜向右上"是喷蒸汽加湿（焓增 d 增）。

### 1.3 关键关系

- $h = 1.01t + 0.001d(2500 + 1.84t)$（近似）
- $t_l$ = 沿等湿线冷却到 $\varphi = 100\%$ 的温度
- $h$ 沿 $d$ 不变时随 $t$ 增加

## 二、空气系统分类与送风参数

### 2.1 系统分类

| 分类 | 类型 | 特点 |
|------|------|------|
| **按介质** | 全空气系统 | 全部冷/热量由空气承担 |
| | 空气-水系统 | 空气+水共同承担（FCU+新风） |
| | 全水系统 | 仅水（住宅暖气片） |
| | 冷剂系统 | 直膨式（分体、VRV） |
| **按风量** | 定风量（CAV） | 风机转速不变 |
| | 变风量（VAV） | 风机变速、风量调节 |
| **按新回风比** | 直流式 | 100% 新风（医院、实验室） |
| | 一次回风 | 最常用 |
| | 二次回风 | 节能运行 |
| | 排风热回收 | 节能型一次回风 |

### 2.2 送风量计算

$$\boxed{G = \dfrac{Q_s}{1.2 \cdot (t_n - t_o)} \times 3600 \text{ m}^3/\text{h}}$$

或由**热湿比线 + 室内点**确定送风温度，再求风量。

### 2.3 送风状态点确定

**步骤**（焓湿图上操作）：

1. 标出**室内点 N**（$t_n, d_n, h_n$）和**热湿比 $\varepsilon$**
2. 过 N 点作**热湿比线**（连接 $\varepsilon$ 方向）
3. 过 N 点向下作**送风温度线**（$t_o = t_n - \Delta t_o$）
4. 两条线**交点**即为**送风点 O**
5. 由 $Q_s / (\rho c_p \Delta t_o)$ 求送风量

> **送风温差**：
> - 舒适性空调：6～10℃
> - 大空间（高大厂房）：≥ 10℃（避免吹风感需更高风速）
> - 工艺空调：按工艺要求

> **设计含义**：送风温差选大→风量小、风管小、风机小，但送风温度低、易吹风感；反之亦然。需要在初投资、噪声、舒适之间取平衡。

## 三、定风量全空气系统

### 3.1 系统组成

空气处理流程：新风 → 混合室 → 过滤段 → 冷却盘管 → 加热器 → 加湿器 → 再热器 → 送风机 → 散流器 → 房间 → 回风 → 混合室。

| 设备 | 作用 |
|------|------|
| 新风口 | 引入室外新风 |
| 混合室 | 新风+回风混合 |
| 过滤段 | 净化 |
| 冷却盘管 | 降温除湿 |
| 加热器 | 二次加热（避免过冷） |
| 加湿器 | 补充湿度 |
| 送风机 | 输送空气 |
| 散流器 | 末端送入房间 |

### 3.2 处理过程

- **夏季**：新回风混合 → 冷却除湿 → 二次加热（避免过冷）→ 送入
- **冬季**：新回风混合 → 预热 → 加热 → 加湿 → 送入

### 3.3 优缺点

| 优点 | 缺点 |
|------|------|
| 集中管理 | 风管粗、占空间 |
| 过滤好 | 风机能耗大 |
| 易于加湿 | 易吹风感 |
| 适合大空间 | 末端不可调 |

## 四、定风量系统的运行调节

### 4.1 调节方式对比

| 方式 | 调节对象 | 适用 |
|------|---------|------|
| **量调节** | 送风量 $G$ | 送风状态不变 |
| **质调节** | 送风状态 $h_o$ | 风量不变 |
| **混合调节** | 风量+状态都变 | 节能运行 |

### 4.2 焓湿图：质调节分区

将空调运行按室外参数划分为**不同工况区**：
- **冬季最小新风**：$h_w < h_n$，新风+回风 → 预热 → 加热 → 加湿 → 送入
- **夏季最小新风**：$h_w > h_n$，新风+回风 → 冷却除湿 → 二次加热 → 送入
- **过渡季全新风**：$h_w < h_o$ 时，全部用新风，节能

**焓湿图关键点**（夏季）：
- **N**：室内点（已知）
- **W**：室外点（已知）
- **C**：新回风混合点（NW 连线上）
- **L**：机器露点（$\varphi = 90\sim95\%$）
- **O**：送风点（热湿比线与送风温度线交点）

处理路径：$N \to C$（不画，实际是混合过程）→ $L$（冷却去湿）→ $O$（再热）。

**质调节节能**：二次回风 vs 再热对比。**二次回风省再热量**——把"再热"用**回风混合**代替，节能明显。

### 4.3 二次回风系统

**原理**：
1. 新风 + 一次回风 → 一次混合点 $C_1$
2. 冷却到露点 $L$
3. 露点空气 + 二次回风 → 二次混合点 = 送风点 $O$
4. **不耗再热量** = 节能

**适用**：送风温差大、潜热负荷小的场合。

#### 4.3.0 从房间负荷出发的完整推导（教材公式链）

> 本节从**房间冷负荷 $Q$（kW）** 出发，用能量守恒和质量守恒**链式推导**教材中出现的 5 个核心公式。这是理解二次回风计算流程的**唯一正确起点**——所有风量和冷量都源于房间负荷 $Q$。

**符号**（单位均为 kg/h，焓单位 kJ/kg）：

| 符号 | 含义 | 教材常见称呼 |
|------|------|-------------|
| $Q$ | 房间**全冷负荷**（kW） | 冷负荷 |
| $G_S$ | **计算送风量**（送入房间的总风量） | 送风量 |
| $G_O$ | **通过喷水室的风量**（= 露点风量） | 喷水室风量 / 机器露点风量 |
| $G_{R2}$ | 二次回风量（旁通喷水室） | 二次回风量 |
| $G_{R1}$ | 一次回风量（与新风混合后进入喷水室） | 一次回风量 |
| $G_N$ | 新风量（卫生要求 ≥ $0.15 G_S$） | 新风量 |
| $h_R$ | 室内状态点焓 | — |
| $h_O$ | 送风状态点焓 | — |
| $h_L$ | 机器露点焓 | — |
| $h_{C_1}$ | 一次混合点焓（新风 + 一次回风混合后） | — |

---

**第 1 步：计算送风量 $G_S$（房间能量守恒）**

送风 $O$ 进入房间 → 吸收冷负荷 $Q$ → 状态变为回风 $R$：

$$\boxed{Q = G_S \cdot (h_R - h_O)}$$

解得：

$$\boxed{G_S = \dfrac{Q}{h_R - h_O}}$$

> **物理含义**：$G_S$ 决定了"多少风量"才能在送风温差 $\Delta t_S = t_R - t_O$ 下带走热量 $Q$。送风温差越大 → $G_S$ 越小 → 风机节能。

---

**第 2 步：计算喷水室风量 $G_O$（系统能量守恒）**

在二次混合点 $O$，露点空气 $L$ 与旁通回风 $R$ 按风量加权混合：

$$h_O = \dfrac{G_O \cdot h_L + G_{R2} \cdot h_R}{G_S}$$

代入 $Q = G_S \cdot (h_R - h_O)$ 消去 $h_O$ 和 $G_{R2}$ 得：

$$\boxed{Q = G_O \cdot (h_R - h_L)}$$

解得：

$$\boxed{G_O = \dfrac{Q}{h_R - h_L}}$$

> **为什么是 $h_R - h_L$ 而不是 $h_{C_1} - h_L$？** 因为 $Q$ 是房间总负荷，$G_O \cdot (h_R - h_L)$ 等于"如果所有送风都走喷水室，完成为房间除热所需的焓降总量"。而 $G_O \cdot (h_{C_1} - h_L)$ 是**冷盘管实际提供的冷量**（第 5 步单独计算）。

---

**第 3 步：计算二次回风量 $G_{R2}$（质量守恒）**

送风总量 $G_S$ 走两条路径汇合：

$$\boxed{G_{R2} = G_S - G_O}$$

代入 $G_S$ 和 $G_O$ 的表达式：

$$G_{R2} = \dfrac{Q}{h_R - h_O} - \dfrac{Q}{h_R - h_L} = Q \cdot \dfrac{h_O - h_L}{(h_R - h_O)(h_R - h_L)}$$

> **为什么要减去？** 喷水室只处理了 $G_O$ 风量，剩下的 $G_{R2}$ 旁通直接送入房间。两条路径在 $O$ 点汇合——这正是"二次回风"的物理含义：**用旁通代替再热，省去再热器**。

---

**第 4 步：计算一次回风量 $G_{R1}$（喷水室质量守恒）**

喷水室入口的风量组成：

$$\boxed{G_O = G_N + G_{R1}}$$

解得：

$$\boxed{G_{R1} = G_O - G_N}$$

> **物理含义**：进入喷水室的空气由"必须处理的新风 + 选配的一次回风"组成。新风 $G_N$ 必须经过喷水室（冷却去湿达到室内含湿量要求）；一次回风 $G_{R1}$ 是"自愿"通过喷水室的部分回风，用来凑足 $G_O$ 的总量。

---

**第 5 步：计算机组冷量 $Q_{ch}$（喷水室冷盘管）**

喷水室（冷盘管）把一次混合点 $C_1$ 的空气冷却去湿到露点 $L$：

$$\boxed{Q_{ch} = G_O \cdot (h_{C_1} - h_L)}$$

其中一次混合点焓 $h_{C_1}$：

$$h_{C_1} = \dfrac{G_N \cdot h_N + G_{R1} \cdot h_R}{G_O}$$

或者等价地：

$$\boxed{Q_{ch} = G_N \cdot h_N + G_{R1} \cdot h_R - G_O \cdot h_L}$$

> **与第 2 步的区别**：第 2 步的 $G_O \cdot (h_R - h_L)$ 是"房间角度的等效焓降"；第 5 步的 $G_O \cdot (h_{C_1} - h_L)$ 是**冷盘管实际承担的冷量**。两者不同，因为 $h_{C_1} \neq h_R$（一次混合点含新风，焓低于 $h_R$）。

---

**数值验证**（接续 §4.3.3 的已知参数）：

- $Q = G_S \cdot (h_R - h_O) = 10000 \times (56.3 - 43.4) = 129000$ kJ/h = **35.83 kW**
- $G_S = 10000$ kg/h ✓
- $G_O = Q / (h_R - h_L) = 129000 / (56.3 - 34.2) = 129000 / 22.1 = 5837$ kg/h ≈ 5840 kg/h ✓
- $G_{R2} = G_S - G_O = 10000 - 5840 = 4160$ kg/h ✓
- $h_{C_1} = (1500 \times 84.5 + 4340 \times 56.3) / 5840 = (126750 + 244342) / 5840 = 63.54$ kJ/kg
- $Q_{ch} = 5840 \times (63.54 - 34.2) = 5840 \times 29.34 = 171345$ kJ/h = **47.60 kW**

**差异分析**：$Q_{ch} (47.60 \text{ kW}) > Q (35.83 \text{ kW})$，**差额 = 新风附加冷负荷**（新风焓 $h_N$ 远高于 $h_R$，室外空气冷却到露点需要的额外冷量）。

---

**公式链总结**（教材计算顺序）：

$$\boxed{G_S = \dfrac{Q}{h_R - h_O} \;\xrightarrow{\text{能量守恒}}\; G_O = \dfrac{Q}{h_R - h_L} \;\xrightarrow{\text{质量守恒}}\; G_{R2} = G_S - G_O \;\xrightarrow{\text{质量守恒}}\; G_{R1} = G_O - G_N \;\xrightarrow{\text{能量守恒}}\; Q_{ch} = G_O \cdot (h_{C_1} - h_L)}$$

> 五个公式互锁验证：$G_{R2} + G_O = G_S$，$G_N + G_{R1} = G_O$，$Q = G_S (h_R - h_O) = G_O (h_R - h_L)$，$Q_{ch} = G_O (h_{C_1} - h_L) \neq Q$（含新风附加）。

#### 4.3.1 风量构成与质量守恒

**符号约定**（单位均为 kg/h，下同）：

| 符号 | 含义 |
|------|------|
| $G_S$ | **计算送风量**（送入房间的总风量） |
| $G_N$ | 新风量（由卫生要求 $G_N \geq 0.15 G_S$ 或正压要求决定） |
| $G_{R1}$ | 一次回风量（与新风混合后经喷水室） |
| $G_{R2}$ | 二次回风量（与露点空气再混合旁通） |
| $G_O$ | **喷水室处理风量** = 露点风量（经过冷却去湿的风量） |

**质量守恒**（系统任意节点进出风量相等）：

$$\boxed{G_S = G_N + G_{R1} + G_{R2}}$$

经过喷水室（冷却去湿）的风量是「新风 + 一次回风」：

$$G_O = G_N + G_{R1}$$

代入上式得 **二次回风量公式**（即用户所问的「为什么 = 计算送风量 − 喷水室风量」）：

$$\boxed{G_{R2} = G_S - G_O = G_S - (G_N + G_{R1})}$$

> **物理意义**：二次回风「旁路」喷水室，是未经过冷却去湿的室内回风。送风总量 $G_S$ 走两条路径：① 经过喷水室（$G_O$），② 旁通二次回风（$G_{R2}$）。两条路径汇合后共同送入房间。

#### 4.3.2 夏季工况：送风温差如何决定二次混合点

**焓湿图全过程**（夏季）：

```
N（新风）┐
         ├─→ C₁（一次混合点）─→ L（露点，喷水室冷却去湿）─┐
R（回风）┘                                                  ├─→ O（送风点）──→ 房间
                                                          ┘
                                              R（旁通二次回风）
```

**由能量守恒求二次回风量**（C₁ 焓 + R 焓混合成 O 焓）：

$$G_O \cdot h_L + G_{R2} \cdot h_R = G_S \cdot h_O$$

代入 $G_{R2} = G_S - G_O$：

$$G_O \cdot h_L + (G_S - G_O) \cdot h_R = G_S \cdot h_O$$

解出二次回风量比：

$$\boxed{\dfrac{G_{R2}}{G_S} = \dfrac{h_O - h_L}{h_R - h_L}}$$

或者等价地求喷水室处理风量比：

$$\boxed{\dfrac{G_O}{G_S} = \dfrac{h_R - h_O}{h_R - h_L}}$$

> **送风温差决定混合点**：送风温度 $t_O$ 越高 → $h_O$ 越大 → $G_{R2}/G_S$ 越大（多走旁通、少走盘管）。极端情况：
> - $t_O = t_L$（送风温度 = 露点温度）→ $G_{R2} = 0$，全部经喷水室
> - $t_O = t_R$（送风温度 = 回风温度）→ $G_{R2} = G_S$，全部旁通（不现实）

#### 4.3.3 数值算例

**已知**（夏季工况）：
- 室内参数 $t_R = 26$°C，$\varphi_R = 55\%$ → $h_R = 56.3$ kJ/kg，$d_R = 12.0$ g/kg
- 露点参数 $t_L = 12$°C，$\varphi_L = 95\%$ → $h_L = 34.2$ kJ/kg，$d_L = 8.4$ g/kg
- 送风温度 $t_O = 18$°C，$d_O = 8.4$ g/kg（露点等含湿量加热）→ $h_O = 43.4$ kJ/kg
- 新风比 $X_N = G_N/G_S = 0.15$

**计算二次回风量比**：

$$\dfrac{G_{R2}}{G_S} = \dfrac{43.4 - 34.2}{56.3 - 34.2} = \dfrac{9.2}{22.1} = 0.416$$

设 $G_S = 10000$ kg/h，则：
- $G_{R2} = 4160$ kg/h（**42% 风量走旁通**）
- $G_O = 10000 - 4160 = 5840$ kg/h（**58% 风量过喷水室**）
- $G_N = 0.15 \times 10000 = 1500$ kg/h
- $G_{R1} = G_O - G_N = 5840 - 1500 = 4340$ kg/h

**验算**（能量守恒）：
$$G_O \cdot h_L + G_{R2} \cdot h_R = 5840 \times 34.2 + 4160 \times 56.3 = 199728 + 234208 = 433936 \text{ kJ/h}$$
$$G_S \cdot h_O = 10000 \times 43.4 = 434000 \text{ kJ/h} \checkmark \text{（误差 < 0.02%）}$$

#### 4.3.4 冬季工况

**冬季特殊性**：室外新风温度低、含湿量低，需要先**预热**再混合。处理路径：

```
N（新风，冬季）→ 预热 → 与一次回风混合 C₁ → 喷水室（喷循环水，等焓加湿）→ L
  → 与二次回风混合 → O（送风点）──→ 房间
```

**冬季 $G_{R2}/G_S$ 公式**（形式相同）：

$$\dfrac{G_{R2}}{G_S} = \dfrac{h_O - h_L}{h_R - h_L}$$

但**冬季 $h_L$ 含义不同**——是喷水室喷循环水**等焓加湿**后的露点（机器露点，不是机器饱和点）。$h_L$ 接近 $h_{C_1}$，因为等焓过程 $h$ 不变。

**冬季典型数据**：
- $t_N = -5$°C，$h_N = -1.5$ kJ/kg
- $t_R = 20$°C，$h_R = 38.5$ kJ/kg
- 预热后 $C_1$：$h_{C_1} \approx 15$ kJ/kg
- 等焓加湿后 $L$：$h_L \approx 15$ kJ/kg（$h$ 不变）
- 送风点 $O$：$t_O = 25$°C → $h_O \approx 50$ kJ/kg
- 算得 $G_{R2}/G_S = (50-15)/(38.5-15) = 1.49$ **> 1** ❌ **不合理**

**说明**：冬季送风温度 $t_O$ 高于 $t_R$ 是加热过程，需要**再热器**配合，二次回风无法完全替代再热。所以二次回风**主要适用于夏季**（冷却去湿后需要升温），冬季一般不采用二次回风系统（采用一次回风 + 预热 + 再热更合理）。

#### 4.3.5 工程设计要点

| 设计参数 | 经验值 | 备注 |
|---------|-------|------|
| 新风比 $X_N$ | 10%~30% | 卫生要求 ≥ 15%，正压要求更大 |
| 送风温差 $\Delta t_S$ | 6~10°C（一般空调）<br>14~18°C（高负荷车间） | $\Delta t_S$ 越大 → $G_S$ 越小 → 风机节能 |
| 露点温度 $t_L$ | 10~14°C | 取决于 $t_{WS}$（湿球温度）和机器饱和效率 |
| 一次回风比 $G_{R1}/G_O$ | 70%~90% | 由新风比反推 |
| 二次回风比 $G_{R2}/G_S$ | 30%~50%（夏季典型） | 送风温差越大，比值越大 |

**节能对比**（与一次回风 + 再热对比）：

- 一次回风 + 再热：再热量 $Q_{RH} = G_S \cdot \rho \cdot c_p \cdot (t_O - t_L)$
- 二次回风：再热量 ≈ 0，节省 $Q_{RH}$
- 节省能耗 ≈ $G_S \cdot \rho \cdot c_p \cdot (t_O - t_L)$（约 30%~50% 的总冷量）

### 4.4 焓湿图全过程

**夏季一次回风**：新回风混合 → $C$ → 冷却去湿到 $L$（$\varphi = 90\sim95\%$）→ 再热到 $O$。

**夏季二次回风**：新+一次回风 → $C_1$ → 冷却到 $L$ → 二次回风混合 = $O$。

## 五、变风量空调系统

### 5.1 节能原理

- **部分负荷**时减少送风量
- 风机功率 ∝ 风量³ → 降风量 50% 节能 ~85%
- 比定风量系统**节能 30～50%**

### 5.2 系统组成

AHU（空调机组）通过主风管向各房间的 VAV 末端送风，每个房间的 VAV 末端独立调节风量。AHU 定新风比（最小新风阀 + 最大新风阀两段），保证各房间最小新风量。

- **AHU**：定新风比（最小新风阀 + 最大新风阀）
- **VAV 末端**：每个房间独立调节风量
- **最小风量限制**：保证新风量

### 5.3 控制方式对比

| 方式 | 风机控制 | 特点 |
|------|---------|------|
| **定静压** | 维持主风管某点静压恒定 | 简单、节能一般 |
| **变静压** | 最低静压满足最不利 VAV | **更节能**（主流） |
| **总风量控制** | 直接按总需求调节 | 需精确传感器 |

### 5.4 变静压控制（VSP）

- 主风管**所有 VAV 都全开时**的静压 = **最低静压**设定值
- 风机转速自动跟踪这个静压
- 节能 20～30%（比定静压）

> **节能的 3 个层次**：
> 1. 比定风量节能（基本）
> 2. 变静压比定静压节能
> 3. 总风量控制再节能

### 5.5 与最小新风量结合

- 任何工况都保证**最小新风量**（卫生）
- 过渡季可加大新风比直至**全新风**
- 与"焓湿图质调节"中的最小新风工况统一

### 5.6 优缺点

| 优点 | 缺点 |
|------|------|
| 节能显著 | 初投资高 |
| 个性化调节 | 控制系统复杂 |
| 无冷热抵消 | 新风量分配不均 |
| 适合办公楼 | 噪声控制难 |

## 六、空气-水风机盘管系统

### 6.1 系统组成

**新风机组（AHU）** 集中处理新风后通过新风总管送入各房间，**风机盘管（FCU）** 处理各房间的室内循环风，水管（冷/热水）从冷热源接至各 FCU。

- **FCU（Fan Coil Unit）**：处理室内循环风
- **新风机组**：集中处理新风后送入各房间

### 6.2 焓湿图任务分配

新风机组与 FCU **任务分配**有多种组合：

**方案 A：新风承担全部湿负荷，FCU 承担显热**
- 新风处理到露点 $L$（AHU 出风）
- 露点新风与室内空气混合
- FCU 干工况（只承担显热，不除湿）

**方案 B：FCU 干工况运行，新风承担湿负荷**
- FCU 只加热/不除湿
- 新风集中除湿后送入

**方案 C：FCU 湿工况运行**
- FCU 承担部分湿负荷
- 新风量小（仅满足卫生）

### 6.3 各种组合工况对比

| 方案 | 新风量 | FCU 形式 | 适用 |
|------|-------|---------|------|
| **A** | 全部湿负荷 | 干工况 | 高级办公 |
| **B** | 全部湿负荷 | 干工况 | 室内无湿源 |
| **C** | 卫生量 | 湿工况 | 餐厅、商业 |

> **设计选择依据**：
> - 室内湿源少（办公）→ 方案 A 或 B，新风集中除湿
> - 室内湿源多（餐厅、商业）→ 方案 C，FCU 也除湿
> - 方案 A 比 B 风量大（除湿多），但 FCU 简单；方案 C 节能但控制复杂

### 6.4 优缺点

| 优点 | 缺点 |
|------|------|
| 末端独立控制 | 维护工作量大 |
| 节能（分区） | 过滤差（FCU 简易） |
| 风管小 | 加湿困难 |
| 适合公寓酒店 | 凝结水处理 |

## 七、冷剂式空调与多联机

### 7.1 冷剂式系统分类

| 类型 | 组成 | 适用 |
|------|------|------|
| **单元式** | 1 室外 + 1 室内 | 住宅 |
| **多联机 VRF/VRV** | 1 室外 + N 室内 | 中小型公建 |
| **热回收 VRV** | 同时制冷+制热 | 综合楼 |
| **水环热泵** | N 个独立水环热泵 | 大型公建 |

### 7.2 多联机（VRV）系统

1 台室外机通过冷媒管连接多台室内机，每台室内机可独立开关与温度控制。

**配比系数**：

<div class="formula-box">配比系数 = <span class="formula-frac"><span class="formula-frac-num">室内机总额定容量</span><span class="formula-frac-den">室外机额定容量</span></span> = 50% ～ 130%</div>

- 50～100%：**同时使用系数低**（住宅、公寓）
- 100～130%：**超配**（办公，部分房间同时开）
- 超过 130% 不可靠

### 7.3 热回收 VRV

- **同时**部分房间制冷、部分制热
- 冷凝热直接转移到需热的房间（**不经过冷却塔**）
- 节能 30～50%（相比普通 VRV）

**适用**：办公建筑（核心筒内外侧温差大）

### 7.4 水环热泵

每个房间独立设置一台水环热泵，通过公共水环路连接。夏季水环放热到冷却塔，冬季水环吸热自锅炉。**适合内外分区**：外围房间冷、内区热——内区热泵放热到水环，外围房间热泵从水环吸热。

- **每个房间**独立热泵
- 水环只承担"室内冷凝热的转移"
- 夏季放热、冬季吸热

### 7.5 对比总结

| 类型 | 节能 | 调节 | 维护 | 初投资 |
|------|------|------|------|-------|
| 单元式 | ★ | ★ | ★★★ | ★ |
| VRV 普通 | ★★★ | ★★★ | ★★ | ★★ |
| **热回收 VRV** | **★★★★★** | ★★★★ | ★★ | ★★★ |
| 水环热泵 | ★★★★ | ★★★★★ | ★ | ★★★★ |
