# 气流组织

气流组织是空调末端的"最后一公里"，决定室内温湿度场、污染物分布和热舒适性。

---

## 一、要求与评价

### 1.1 基本要求

1. **工作区**温湿度均匀
2. 满足清洁度（稀释污染物）
3. 噪声低（风口风速受限）
4. 不吹风感（人员活动区风速 ≤ 0.3 m/s）
5. 节能（合理利用自然对流）

### 1.2 评价指标

| 指标 | 含义 | 典型值 |
|------|------|-------|
| **温度不均匀系数 $k_t$** | 测点温差/平均温差 | ≤ 0.15～0.3 |
| **速度不均匀系数 $k_v$** | 测点速差/平均速差 | ≤ 0.3 |
| **空气分布特性指标 ADPI** | 同时满足温度速度的测点比例 | ≥ 80% |
| **能量利用系数 $\eta_t$** | 实际利用/理想利用 | ≥ 0.8 |
| **排污效率** | 工作区浓度/排风浓度 | 越接近 1 越好 |

<div class="formula-box">ADPI = <span class="formula-frac"><span class="formula-frac-num">满足 -1.5 &lt; Δt &lt; 1.1 的测点数</span><span class="formula-frac-den">总测点数</span></span> × 100%</div>

### 1.3 送风参数选择

- **送风温差 Δt_o**（6～10℃）
- **送风速度 v_o**（2～5 m/s，侧送）
- **风口间距 L**（按射程确定）

---

## 二、送风口与回风口

### 2.1 送风口类型

| 类型 | 特点 | 适用 |
|------|------|------|
| **侧送百叶** | 贴顶/侧墙，水平/角度送 | 通用、办公 |
| **散流器** | 顶送，气流贴附 | 集中空调 |
| **孔板** | 大面积均匀送 | 洁净室 |
| **喷口** | 高速远射 | 大空间（厅堂、体育馆） |
| **旋流风口** | 旋转气流 | 工业大空间 |

### 2.2 风口形式与气流

- 侧送 → 贴附射流 → 工作区
- 顶送散流器 → 下送气流 → 工作区
- 孔板 → 平行流 → 洁净室
- 喷口 → 远射 → 大空间

### 2.3 风口选择原则

- 送风温差大 → 侧送（贴附）
- 室温精度高 → 孔板/旋流
- 大空间 → 喷口
- 洁净 → 孔板（FFU）
- 回风口：风速 ≤ 1.5～2 m/s（噪声）

## 三、典型气流分布模式

### 3.1 上送下回

顶部送风下送 → 工作区 → 底部回风。

- **最常用**
- 新风先到顶部（不影响工作区）
- 回风带走污染物和余热

### 3.2 上送上回

- 适用：发热设备**位于顶部**或回风不便
- 缺点：工作区可能温度偏高

### 3.3 下送上回

- 适用：地板送风、置换通风
- 新鲜空气直接到工作区
- 节能但地面需架空

### 3.4 中送

- 适用：大空间分层空调（体育馆、剧场）
- 仅空调下部区域

### 3.5 置换通风

地面低速送风 → 冷空气下沉 → 工作区 → 热污染上升 → 顶部回风。送风速度极低（0.2～0.3 m/s），温度略低于室温，利用**热羽流**自然驱动，节能且空气品质高。

## 四、气流分布的设计计算

### 4.1 设计步骤

1. 选择送风方式（上送下回等）
2. 计算送风量（已知 Qs 和 Δt_o）
3. 选择风口类型和数量
4. 计算风口尺寸
5. 校核射程与贴附长度
6. 校核噪声

### 4.2 风口尺寸

$$\boxed{F = \dfrac{L}{3600 \cdot v_o}}$$

- $L$：单风口风量（m³/h）
- $v_o$：风口风速（m/s）
- $F$：风口有效面积（m²）

### 4.3 侧送贴附射程

$$L_{a} = 0.5 \cdot \dfrac{v_o \cdot d}{\alpha}$$

- $L_a$：贴附射程

- $d$：风口当量直径
- $\alpha$：射流衰减系数（0.07～0.2）

### 4.4 校核

- 射程 ≤ 房间长度 0.7 倍
- 贴附长度 ≥ 房间长度
- 风口间距 2～4 m

### 4.5 噪声控制

- 风口风速限制：$v_o \leq 2 \sim 5$ m/s（依房间允许噪声）
- 送风管风速限制：$v \leq 4 \sim 8$ m/s（主风管）
- 消声器、消声弯头
