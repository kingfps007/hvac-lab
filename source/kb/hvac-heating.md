# 供暖系统

供暖系统在冬季为建筑补足热损失，维持室内设计温度。本章涵盖散热器、系统形式、高层分区、热计量、**水力计算**和辐射供暖。

---

## 一、散热器

### 1.1 类型对比

| 类型 | 材质 | 特点 | 适用 |
|------|------|------|------|
| 铸铁柱型 | 铸铁 | 耐腐蚀、寿命长 | 传统住宅 |
| 钢制柱型 | 钢 | 美观、重量轻 | 现代住宅 |
| 钢制板型 | 钢 | 散热量大、紧凑 | 公共建筑 |
| 铝制 | 铝合金 | 散热量大 | 注意水质 |
| 铜铝复合 | 铜+铝 | 耐腐蚀 | 高水质要求 |

### 1.2 散热器放热系数 η

$$\boxed{\eta = \dfrac{t_n - t_o}{t_n - t_w}}$$

- $t_n$：室内温度
- $t_o$：室外供暖计算温度
- $t_w$：散热器内**平均水温**

物理意义：**实际放热量与最大可能放热量（$t_w = t_n$ 时）之比**。$\eta$ 越大说明散热器工作温度与室温越接近，利用率越高。

### 1.3 选型

$$Q_k = K \cdot F \cdot \Delta t_m$$

- $Q_k$：散热器散热量（W）
- $K$：传热系数（W/(m²·K)）
- $F$：散热面积（m²）
- $\Delta t_m$：对数平均温差

**步骤**：
1. 计算房间热负荷 $Q$（W）
2. 加上 20～30% 富裕量
3. 查散热器样本 → 选定型号和片数

## 二、室内热水供暖系统

### 2.1 系统分类

| 分类方式 | 类型 | 特点 |
|---------|------|------|
| **按循环动力** | 自然循环（重力） | 无水泵、靠密度差、易失调 |
| | 机械循环 | 有水泵、调节方便 |
| **按供回水温度** | 低温（≤ 95℃） | 地暖兼容 |
| | 高温（> 100℃） | 散热器 |
| **按管道敷设** | 垂直单管 | 构造简单、不易调节 |
| | 垂直双管 | 可独立调节、易竖向失调 |
| | 水平单管 | 适合分户计量 |

### 2.2 双管系统竖向失调

顶层散热器（上层重力小）作用压头大 → 过流量大 → 上层过热；底层散热器（下层重力大）作用压头小 → 过流量小 → 下层过冷。

> **物理原因**：双管系统每个散热器支路都形成独立"自然压头"。底层散热器承受水柱重力差最大，**额外压头抵消水泵压头**，导致过流量不足；顶层反之。
>
> **解决方法**：
> - 高层建筑采用**分区式**（竖向断开）
> - 顶层加平衡阀
> - 改用单管系统

### 2.3 同程 vs 异程

- **异程**：供水顺序与回水顺序相反 → 近端阻力小、远端阻力大
- **同程**：供水与回水路径等长 → 阻力平衡好
- 异程系统应装**平衡阀**或放大管径

### 2.4 机械循环 vs 重力循环：偏导数量化对比

> 本节用偏导数严格量化两种循环方式的失调敏感性，回答三个核心问题：
> （1）哪个更容易失调；（2）如何用偏导数量化计算；（3）机械循环何时不如重力。

#### 2.4.1 物理模型

**双管系统**每个散热器支路（编号 $i=1...N$，$i=1$ 为最底层）的压头平衡方程：

$$\boxed{H_p + H_{g,i} = S_i \cdot G_i^2}$$

**参数定义**：
- $H_p$ — 水泵压头（Pa）。**机械循环**：$H_p \gg H_{g,i}$；**重力循环**：$H_p = 0$
- $H_{g,i} = g \cdot h_i \cdot (\rho_{avg} - \rho_i)$ — 第 $i$ 个散热器的**自然压头**（Pa）。$h_i$ 为散热器相对热源的高差（m），$\rho_{avg}$ 为热源平均水密度，$\rho_i$ 为散热器内水密度
- $S_i$ — 第 $i$ 支路的总阻力系数（沿程 + 局部，单位 Pa/(kg/h)²）
- $G_i$ — 第 $i$ 支路流量（kg/h）

**由压头平衡解出流量**：

$$G_i = \sqrt{\dfrac{H_p + H_{g,i}}{S_i}}$$

**关键设计点**：$H_{g,i}$ 与 $h_i$ 成正比——底层散热器承受的水柱重力差最大，自然压头**最大**；顶层最小。这是双管系统竖向失调的物理根源。

#### 2.4.2 偏导数推导

将 $G_i$ 视为 $H_p$ 和 $H_{g,i}$ 的函数，求一阶偏导：

$$\dfrac{\partial G_i}{\partial H_p} = \dfrac{1}{2\sqrt{S_i \cdot (H_p + H_{g,i})}}$$

$$\dfrac{\partial G_i}{\partial H_{g,i}} = \dfrac{1}{2\sqrt{S_i \cdot (H_p + H_{g,i})}}$$

**失调率**（实际流量与设计流量的相对偏差）：

$$\sigma_i = \dfrac{G_i - G_{i,\text{design}}}{G_{i,\text{design}}}$$

**对热负荷变化 $Q_i$ 的灵敏度**（质调节时 $Q_i$ 变化 → 进水温度变化 → 密度差变化 → $H_{g,i}$ 变化）：

$$\dfrac{\partial \sigma_i}{\partial Q_i} = \dfrac{1}{G_{i,\text{design}}} \cdot \dfrac{\partial G_i}{\partial H_{g,i}} \cdot \dfrac{\partial H_{g,i}}{\partial Q_i}$$

> **三项含义**（自左至右）：
> （1）$\dfrac{1}{G_{i,\text{design}}}$ — **归一化**因子（把绝对偏差转为相对偏差）
> （2）$\dfrac{\partial G_i}{\partial H_{g,i}}$ — **流量灵敏度**（自然压头变化对流量的影响率）
> （3）$\dfrac{\partial H_{g,i}}{\partial Q_i}$ — **自然压头灵敏度**（热负荷变化对自然压头的影响率）

记 $H_{\text{tot},i} = H_p + H_{g,i}$，则**失调率对热负荷的全微分**：

$$\boxed{d\sigma_i = \dfrac{1}{2 G_{i,\text{design}} \sqrt{S_i H_{\text{tot},i}}} \cdot \dfrac{\partial H_{g,i}}{\partial Q_i} \cdot dQ_i}$$

> **物理意义**：$d\sigma_i$ 表示当 $Q_i$ 变化 $dQ_i$ 时，第 $i$ 支路的流量失调率变化量。$|d\sigma_i|$ 越大 → 该支路越容易失调。

#### 2.4.3 量化比较

**定义失调度** $\Sigma$ 为各支路失调率的标准差：

$$\Sigma = \sqrt{\dfrac{1}{N}\sum_{i=1}^{N}\sigma_i^2}$$

**机械循环**（$H_p \gg H_{g,i}$，如 $H_p = 10^4$ Pa，$H_{g,i} \sim 10^2$ Pa）：

$$H_{\text{tot},i} \approx H_p \Rightarrow \sqrt{S_i H_{\text{tot},i}} \approx \sqrt{S_i H_p}$$

各支路偏导数差异**极小**（仅由 $S_i$ 的差异决定） → 失调度 $\Sigma_M \to 0$ → **不易失调**。

**重力循环**（$H_p = 0$）：

$$H_{\text{tot},i} = H_{g,i} \Rightarrow \sqrt{S_i H_{\text{tot},i}} = \sqrt{S_i H_{g,i}}$$

各支路偏导数差异**大**（$H_{g,i}$ 随 $h_i$ 变化显著） → 失调度 $\Sigma_G$ 通常达到 15%~30% → **容易失调**。

**数值算例**（6 层双管系统，$h_i$ 从底层到顶层为 0~15 m）：

| 楼层 | $h_i$ (m) | $H_{g,i}$ (Pa) | $\sqrt{S_i H_{\text{tot}}}$ (机械, $H_p=10^4$) | $\sqrt{S_i H_{\text{tot}}}$ (重力, $H_p=0$) |
|------|----------|---------------|--------------------------------------------|---------------------------------------|
| 1F | 0 | 0 | $\sqrt{S \cdot 10^4}$ | 0 (无循环) |
| 3F | 6 | 120 | $\sqrt{S \cdot 10120}$ | $\sqrt{S \cdot 120}$ |
| 6F | 15 | 300 | $\sqrt{S \cdot 10300}$ | $\sqrt{S \cdot 300}$ |

重力循环下，1F 支路 $\sqrt{S \cdot H_{\text{tot}}}=0$ → 流量为零（底层失流）→ 失调度 $\Sigma_G$ 极大。机械循环下，各层 $\sqrt{S \cdot H_{\text{tot}}}$ 几乎相同 → 失调度 $\Sigma_M$ 极小。

**结论 1**：**质调节时机械循环远不易失调**（$\Sigma_M \ll \Sigma_G$）。水泵压头"压制"了自然压头的离散性。

#### 2.4.4 机械循环的反向劣势场景

虽然平均失调度更低，但机械循环在以下场景反而**不如重力循环**：

**场景 1：停电 / 水泵故障**
- 机械循环：$H_p = 0$ → 退化为"没有足够自然压头驱动的非完整系统" → 迅速停摆
- 重力循环：$H_p = 0$ 仍是设计工况 → 维持部分循环，**故障存活能力强**

**场景 2：质调节深度过大（室外温度接近 0°C 甚至更低）**
- 此时室内外温差小 → 热负荷小 → 水泵变频降到极低转速 → $H_p$ 下降到与 $H_{g,i}$ 同数量级 → 偏导数差异又显现 → 出现"机械循环下的重力型失调"

**场景 3：高层建筑底层超压**
- 机械循环：水泵压头被高层需要"撑高" → 底层散热器承压远超 1.0 MPa → 需用减压阀或分区
- 重力循环：自然压头本身随高度递增 → 不需要"撑高压头" → 配合分层换热反而更经济

**场景 4：极小流量工况（部分负荷下变频泵过调）**
- 当 $H_p \cdot G^2$ 之积低于 $H_{g,i} \cdot G^2$ 之积时，自然压头的影响被放大 → 机械循环的失调度反超重力循环

**结论 3**：**机械循环在"水泵失效 / 极低负荷 / 高层底层超压"场景下反不如重力循环**。工程上常用"机械循环做主、重力循环做应急"的双系统冗余设计。

#### 2.4.5 工程设计建议

| 工况 | 推荐循环方式 |
|------|------------|
| 普通多层建筑 | 机械循环（质调节 / 量调节） |
| 高层建筑 | 分区机械循环（高区 + 低区分别设泵） |
| 备用 / 应急系统 | 重力循环（独立管路，停电时启用） |
| 小型独立锅炉房 | 机械循环（投资低、控制灵活） |
| 大型区域锅炉房远端用户 | 重力循环（无电力依赖、维护简单） |

**调节性能对比**（质调节 vs 量调节 vs 间歇调节）：
- **机械循环**：水泵变频响应快 → 适合**量调节**和**间歇调节**
- **重力循环**：循环动力由密度差决定 → 调节滞后大 → 适合**质调节**和**手动调节**

**能耗与投资对比**：
- **机械循环**：增加水泵电耗（典型 0.5~2 W/m² 建筑面积），但可减小散热器面积（更紧凑的设计流量）
- **重力循环**：省水泵电费，但散热器面积需放大 10%~15%（流速低、传热系数低），管径也需放大

> **重要提示**：上述偏导数模型假设**单相不可压缩稳态流动**，且各支路 $S_i$ 相同（实际工程中 $S_i$ 受管径、阀门开度影响会有差异）。完整求解需用 Hardy Cross 法或 Newton-Raphson 迭代。

## 三、高层建筑热水供暖

### 3.1 主要问题

1. **竖向失调**：双管系统底层过热、顶层过冷
2. **水静压力过高**：底层散热器超压
3. **系统排气困难**

### 3.2 分区方式

| 方式 | 做法 | 优缺点 |
|------|------|-------|
| **垂直单管串联** | 整楼一根立管 | 简单、不能调节 |
| **分区式** | 每 10～12 层一独立系统 | 调节好、设备多 |
| **双水箱（断流）** | 上下分立管通过换热器 | 隔断压力 |
| **混水连接** | 高区与低区并联 | 节省能量 |

### 3.3 散热器承压

- 铸铁柱型：0.5～0.8 MPa
- 钢制：0.6～1.0 MPa
- 高区底层超压时必须**用分区或减压阀**

## 四、供暖热计量

### 4.1 计量原则

**分户计量、分室调节**是建筑节能的强制要求（GB 50495）。

### 4.2 计量方式

| 方式 | 位置 | 计费原理 |
|------|------|---------|
| **楼栋热量表** | 入口 | 总热量分摊到户 |
| **户用热量表** | 每户入口 | 直接计量 |
| **楼栋+分摊** | 楼栋+户用 | 公共部分按面积分摊 |

### 4.3 分摊方法

- 按面积分摊（最简单）
- 按户用热量表读数分摊
- 按每户安装的**通断时间面积法**分摊

### 4.4 系统要求

- 必须采用**共用立管 + 户内独立系统**（双管或单管跨越）
- 每户装**温控阀**
- 入口装**热量表 + 过滤阀 + 锁闭阀**

## 五、热水供暖系统设计计算

### 5.1 设计步骤

1. 计算建筑热负荷
2. 选定系统形式和散热器
3. 布置管道（绘制系统图）
4. **水力计算**
5. 选择水泵、压力罐
6. 绘制施工图

### 5.2 水力计算基本公式

**比摩阻法**（最常用）：

$$R = \dfrac{\lambda}{d} \cdot \dfrac{\rho v^2}{2}$$

- $R$：单位长度沿程损失（Pa/m）
- $\lambda$：沿程阻力系数
- $d$：管径
- $v$：流速

**局部阻力**：

$$Z = \sum \xi \cdot \dfrac{\rho v^2}{2}$$

**总阻力**：

$$\boxed{\Delta P = R \cdot L + Z}$$

### 5.3 环路平均温降（不等温降法）

热水从锅炉流到末端，温降沿程累加：

$$\boxed{\Delta t_p = \dfrac{\sum G_i \cdot \Delta t_i}{\sum G_i}}$$

- $G_i$：各管段流量
- $\Delta t_i$：各管段温降

> **设计含义**：保证**最不利环路**（最远端）散热器进水温度符合要求。**沿程温降是水力计算的核心约束**。

### 5.4 不等温降水力计算步骤

1. 计算各管段热负荷 $Q_i$
2. 假设供水温度 $t_s$、回水温度 $t_h$
3. 计算管段流量 $G_i = 0.86 Q_i / \Delta t_i$
4. 查表选管径
5. 计算比摩阻 R 和总阻力
6. 检查最不利环路阻力 → 不平衡则调整管径或加平衡阀 → 平衡后选水泵

### 5.5 水力平衡

**目标**：所有并联环路阻力差 ≤ ±15%。

| 方法 | 适用 |
|------|------|
| **同程系统** | 异程改同程 |
| **平衡阀** | 各支路装手动平衡阀 |
| **动态流量平衡阀** | 自力式、随压力变化 |
| **加大管径** | 简单但费管材 |
| **变频泵** | 末端压差控制 |

### 5.6 校核

- 顶层散热器过流量 ≤ 1.3 倍设计流量（防噪声）
- 最远端散热器进出水温差 5～10℃
- 各立管流量偏差 ≤ ±10%

## 六、辐射供暖

### 6.1 分类

| 方式 | 表面温度 | 适用 |
|------|---------|------|
| 低温地板辐射 | 28℃ | 居住建筑 |
| 顶板辐射 | 35℃ | 大空间 |
| 墙面辐射 | 45℃ | 局部 |
| 钢制辐射板 | 60～80℃ | 工业 |

### 6.2 地板辐射设计

- **盘管间距**：100～300mm（边区密、中央疏）
- **供水温度**：35～45℃（低温热水）
- **散热量**：60～200 W/m²
- **构造**：保温层 + 反射层 + 盘管 + 填充层 + 面层

### 6.3 优缺点

| 优点 | 缺点 |
|------|------|
| 温度梯度小（脚暖头凉） | 初投资高 |
| 无吹风感 | 升温慢（蓄热大） |
| 节能 10～20% | 不易检修 |
| 不占墙面 | 地面需抬高 50～80mm |

> 节能的根本原因：**供水温度低**（35～45℃ vs 散热器 95℃），让热源侧可以用热泵（COP 更高），输配侧管路热损更小。

### 6.4 与散热器对比

| 维度 | 散热器 | 地暖 |
|------|-------|------|
| 供水温度 | 95℃ | 35～45℃ |
| 系统 | 高温热水 | 低温热水 |
| 热源 | 锅炉 | 热泵/锅炉均可 |
| 适用 | 既有改造 | 新建 |
