传感器是建筑自动化系统的"感知层"。本知识库覆盖暖通空调领域常用传感器的类型、工作原理、选型参数与安装规范，所有数据基于ASHRAE标准及主流厂家技术手册。

## 1. 温度传感器

### 1.1 铂电阻温度计（RTD: PT100 / PT1000）

| 项目 | 参数 |
|------|------|
| **工作原理** | 铂金属电阻随温度线性变化。PT100在0°C时阻值=100Ω，温度系数α≈0.00385Ω/Ω/°C（IEC 60751标准） |
| **精度等级** | Class A: ±(0.15+0.002\|t\|)°C; Class B: ±(0.30+0.005\|t\|)°C; 1/3 DIN: ±(0.10+0.0017\|t\|)°C |
| **量程** | -200 ~ +850°C（暖通常用 -50 ~ +200°C） |
| **接线方式** | 2线（精度最低）、3线（消除引线电阻，工业最常用）、4线（高精度实验室级） |
| **暖通典型应用** | 风道温度、水管温度、室外温度、房间温度 |
| **输出信号** | 电阻值（直接）/ 4-20mA / 0-10V（带变送器） |

### 1.2 热敏电阻（NTC / PTC）

| 项目 | 参数 |
|------|------|
| **NTC特性** | 负温度系数：阻值随温度升高而降低。常用NTC 10KΩ @25°C (Type II/III曲线) |
| **精度** | ±0.1~±0.5°C（暖通用），互换性较RTD差 |
| **量程** | -40 ~ +150°C |
| **优点** | 灵敏度高(约-4%/°C)、响应快、成本低 |
| **典型应用** | 室内温控器、风机盘管回风温度、DDC AI通用输入 |

### 1.3 热电偶（Thermocouple）

| 项目 | 参数 |
|------|------|
| **类型** | T型(铜-康铜): -200～350°C，精度±0.5°C; K型(镍铬-镍铝): -200～1250°C |
| **暖通场景** | 锅炉烟温、高温管道、冷冻机组排气温度 |
| **局限** | 需要冷端补偿，精度不如RTD |

> 参考文献: *Fraden, J., "Handbook of Modern Sensors", 5th Ed., Springer (2016), Chapter 10*

## 2. 湿度传感器

### 电容式湿度传感器（暖通主流）

| 项目 | 参数 |
|------|------|
| **工作原理** | 高分子薄膜电容随环境相对湿度线性变化，电容值 → RH% |
| **精度** | ±2～3%RH (10-90%RH); ±5%RH (全量程0-100%RH) |
| **量程** | 0-100%RH, -40~+120°C |
| **响应时间** | τ63 ≈ 8～15s（典型值） |
| **输出** | 0-10V / 4-20mA / RS485(MODBUS) / BACnet MS/TP |
| **典型位置** | 新风管、回风管、室内墙面、室外气象站 |
| **安装注意** | 避免阳光直射、远离热源、避免冷凝水滴落 |

> 参考文献: *ASHRAE Guideline 13-2015: Specifying Building Automation Systems*

## 3. 压力/压差传感器

### 压差变送器（暖通最常用压力传感器类型）

| 项目 | 参数 |
|------|------|
| **暖通典型量程** | 微压差: 0～100Pa / 0～500Pa / 0～1000Pa(风管静压、过滤器压差) |
| **精度** | ±1%FS（满量程） |
| **输出** | 0-10V / 4-20mA |
| **典型场景1** | 空调箱风机压差：监测过滤器堵塞状态，压差>设定值报警更换 |
| **典型场景2** | VAV变风量箱流量测量——通过毕托管测压差换算风速 |
| **典型场景3** | 水泵进出口压差——用于水泵变频调速控制 |
| **安装注意** | 高压侧(H)和低压侧(L)接管正确；取压口避开涡流区 |

> 参考文献: *Siemens Building Technologies, "Sensors for HVAC Applications", Technical Guide, 2022*

## 4. 流量传感器

### 电磁流量计（暖通水管流量测量首选）

| 项目 | 参数 |
|------|------|
| **原理** | 法拉第电磁感应定律：导电液体切割磁力线产生感应电动势，E = B·D·v |
| **精度** | ±0.5%读数（高精度）; ±1%读数（常规） |
| **要求** | 流体电导率≥5μS/cm（水完全满足）; 需前后直管段(前5D后3D) |
| **输出** | 4-20mA / 脉冲 / RS485 MODBUS RTU |
| **暖通场景** | 冷冻水总管流量、冷却水流量、换热站热量计 |

### 超声波流量计（非侵入式）

| 项目 | 参数 |
|------|------|
| **类型** | 时差法（Transit-time）: 精度±1～2%；多普勒法：适用于含气泡/颗粒流体 |
| **安装** | 外夹式（无需断管）/ 插入式，无压损 |
| **暖通优势** | 适合大口径管道(DN300+)、改造项目 |

## 5. CO₂与空气质量传感器

### NDIR CO₂传感器（暖通新风控制核心）

| 项目 | 参数 |
|------|------|
| **原理** | 非色散红外吸收(NDIR): CO₂分子吸收4.26μm红外光，吸收强度 → CO₂浓度 |
| **量程** | 0-2000ppm / 0-5000ppm（暖通用0-2000ppm） |
| **精度** | ±(30ppm + 3%读数)（典型） |
| **ABC校准** | 自动基线校准(Automatic Baseline Correction): 定期以室外400ppm为基准自校准 |
| **控制策略** | DCV需求控制通风: CO₂>800ppm开大新风阀, >1000ppm报警, <450ppm关小新风 |
| **ASHRAE 62.1** | 室内CO₂浓度建议≤700ppm(高于室外约300ppm) |

### PM2.5 / VOC / 综合空气质量传感器

| 项目 | 参数 |
|------|------|
| **PM2.5** | 激光散射原理，量程0-1000μg/m³，用于过滤器效率和室内空气质量监测 |
| **VOC** | 金属氧化物半导体(MOX)传感器，输出TVOC ppb/ppm |
| **综合传感器** | 单设备集成温度+湿度+CO₂+PM2.5+VOC，RS485/BACnet输出 |

> 参考文献: *ASHRAE Standard 62.1-2022: Ventilation for Acceptable Indoor Air Quality*

## 6. 暖通传感器选型速查表

| 测量参数 | 推荐传感器类型 | 典型精度 | 典型输出 | 安装位置 |
|---------|-------------|---------|---------|---------|
| 风道温度 | PT1000 / NTC 10K | ±0.2°C (PT) | 4-20mA / NTC | 送/回/新风管 |
| 水管温度 | PT100 (浸入式) | ±0.15°C | 4-20mA / 0-10V | 管道测温套管 |
| 室外温度 | PT1000 + 防辐射罩 | ±0.3°C | 4-20mA | 建筑北侧外墙 |
| 室内温度 | NTC 10K / 数字温湿度 | ±0.3°C | NTC / RS485 | 内墙1.5m高 |
| 风道湿度 | 电容式 | ±3%RH | 0-10V | 回/新风管 |
| 过滤器压差 | 微压差变送器 | ±1%FS | 0-10V / 开关量 | 过滤器前后 |
| 冷冻水流量 | 电磁流量计 | ±0.5%读数 | 4-20mA / RS485 | 供水/回水总管 |
| 室内CO₂ | NDIR | ±(30ppm+3%) | 0-10V / RS485 | 回风区/室内墙 |
