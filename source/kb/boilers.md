# 锅炉设备

锅炉是将燃料的化学能转化为热能，并传递给工质（水或蒸汽）产生蒸汽或热水的设备。本章涵盖锅炉原理、燃烧计算、热平衡及供热锅炉选型。

---

## 一、锅炉设备原理和系统

### 1.1 锅炉分类

| 分类方式 | 类型 | 特点 |
|----------|------|------|
| **用途** | 电站锅炉 | 发电，参数高 |
| | 工业锅炉 | 工业生产用汽 |
| | 供热锅炉（热水锅炉） | 建筑采暖，参数低 |
| **燃料** | 燃煤锅炉 | 成本低，污染大 |
| | 燃气锅炉 | 清洁，自动化高 |
| | 燃油锅炉 | 应急备用 |
| | 电锅炉 | 零排放，运行贵 |
| **结构** | 火管锅炉 | 小型，水在管内 |
| | 水管锅炉 | 大型，汽在管内 |
| **工质** | 蒸汽锅炉 | 产生蒸汽 |
| | 热水锅炉 | 产生热水 |

### 1.2 锅炉基本构造

**主要部件**：

> **燃烧系统**：燃料供应 → 燃烧器 → 炉膛，配以送风机助燃。
> **换热系统**：炉膛 → 水冷壁 → 对流管束 → 省煤器 → 空气预热器，烟气温度逐级降低。
> **汽水系统**：给水泵 → 省煤器 → 水冷壁 → 汽包/集箱 → 蒸汽出口，水/汽循环吸热。
> **排烟系统**：空气预热器 → 除尘器 → 引风机 → 烟囱，处理后排放。

**关键部件功能**：

| 部件 | 功能 |
|------|------|
| 炉膛 | 燃料燃烧空间 |
| 水冷壁 | 辐射换热，保护炉墙 |
| 对流管束 | 对流换热 |
| 省煤器 | 预热给水，降低排烟温度 |
| 空气预热器 | 预热助燃空气，提高效率 |
| 汽包 | 汽水分离，储水 |

### 1.3 供热锅炉系统

**热水锅炉系统**：锅炉 → 供水总管 → 各建筑换热器 → 回水总管 → 循环泵 → 锅炉，配套膨胀水箱或定压装置维持系统压力。

**系统形式**：

| 形式 | 特点 | 应用 |
|------|------|------|
| 一次网直供 | 锅炉直接供末端 | 小型系统 |
| 一次网间供 | 通过换热器 | 中大型系统 |
| 二次网系统 | 一二次网分离 | 区域供热 |

## 二、燃料燃烧计算及锅炉热平衡

### 2.1 燃料特性

**煤的工业分析**：

| 成分 | 符号 | 典型范围 | 影响 |
|------|------|----------|------|
| 水分 | M | 5～15% | 降低发热量 |
| 灰分 | A | 10～30% | 降低效率，磨损 |
| 挥发分 | V | 20～40% | 影响燃烧特性 |
| 固定碳 | FC | 40～60% | 主要发热成分 |

**燃气特性**：

| 参数 | 天然气 | 液化石油气 |
|------|--------|------------|
| 低位发热量 | 35～40 MJ/m³ | 46～50 MJ/kg |
| 理论空气量 | 9.5 m³/m³ | 11.5 m³/kg |
| 理论烟气量 | 10.5 m³/m³ | 12.5 m³/kg |

### 2.2 燃烧计算

**理论空气量**：

对于天然气（以CH₄为主）：
$$V^0 = 0.268 \frac{Q_{net}}{1000} \quad [m³/m³]$$

**过量空气系数**：

$$\alpha = \frac{V_{actual}}{V^0} = \frac{21}{21 - O_2}$$

| 燃烧方式 | 过量空气系数 |
|----------|--------------|
| 燃气锅炉 | 1.05～1.15 |
| 燃油锅炉 | 1.1～1.2 |
| 燃煤锅炉 | 1.2～1.5 |

### 2.3 锅炉热平衡

**输入热量 = 输出热量 + 损失**

$$Q_{in} = Q_{useful} + Q_{loss}$$

**热损失组成**：

| 损失项 | 符号 | 典型值 | 降低措施 |
|--------|------|--------|----------|
| 排烟热损失 | q₂ | 6～12% | 降低排烟温度，预热 |
| 气体不完全燃烧 | q₃ | 0～2% | 优化配风 |
| 固体不完全燃烧 | q₄ | 0～10% | 提高燃烧效率 |
| 散热损失 | q₅ | 1～3% | 保温 |
| 灰渣物理热 | q₆ | 0～2% | 回收 |

**锅炉效率**：

**正平衡法**：
$$\eta = \frac{Q_{useful}}{Q_{in}} \times 100\%$$

**反平衡法**：
$$\eta = 100\% - (q_2 + q_3 + q_4 + q_5 + q_6)$$

**燃气锅炉效率**：
- 常规锅炉：85～90%
- 冷凝锅炉：95～108%（回收潜热）

## 三、供热锅炉

### 3.1 供热锅炉选型

**热负荷计算**：

$$Q = q \cdot F \cdot 10^{-3} \quad [MW]$$

其中：$q$ 为热指标(W/m²)，$F$ 为建筑面积(m²)

**热指标参考**：

| 建筑类型 | 热指标(W/m²) |
|----------|--------------|
| 住宅 | 40～60 |
| 办公楼 | 50～70 |
| 商场 | 60～80 |
| 医院 | 65～85 |

**锅炉台数选择**：

| 总负荷 | 推荐台数 | 单台容量 |
|--------|----------|----------|
| < 1 MW | 2台 | 50～70% |
| 1～5 MW | 2～3台 | 50～70% |
| > 5 MW | 3～4台 | 30～50% |

> **原则**：任何一台检修时，其余锅炉能满足65～75%负荷

### 3.2 燃气热水锅炉

**结构特点**：
- 全湿背式或中心回燃式
- 波纹炉胆，强化换热
- 全自动燃烧控制

**性能参数**：

| 参数 | 范围 |
|------|------|
| 供回水温度 | 95/70°C 或 60/50°C |
| 工作压力 | 常压或承压(≤1.6 MPa) |
| 效率 | 90～95%（常规）/ 100～108%（冷凝） |
| 调节比 | 3:1 ~ 5:1 |

**冷凝锅炉**：
- 原理：回收烟气中的水蒸气潜热
- 排烟温度：40～60°C（vs 常规120～160°C）
- 效率：可达108%（以低位发热量为基准）
- 回水温度要求：≤50°C

### 3.3 电锅炉

**类型**：
- 电阻式：直接加热
- 电极式：利用水电阻
- 蓄热式：低谷蓄热，高峰供热

**适用场景**：
- 环保要求严格地区
- 燃气无法接入
- 峰谷电价差大的地区（配合蓄热）

### 3.4 锅炉房设计要点

**选址要求**：
- 靠近热负荷中心
- 燃料运输方便
- 烟囱排放符合环保要求
- 安全间距满足规范

**系统配置**：

| 系统 | 功能 |
|------|------|
| 水处理 | 软化、除氧、加药 |
| 定压 | 膨胀水箱或定压罐 |
| 循环 | 循环泵（一用一备） |
| 补水 | 补水泵、水箱 |
| 控制 | 气候补偿、分时段控制 |

## 四、锅炉运行与节能

### 4.1 运行调节

**质调节**：改变供水温度
- 根据室外温度调整
- 保持流量不变

**量调节**：改变循环水量
- 变频泵调节
- 配合质调节

**分时段控制**：
- 工作日/节假日不同设定
- 夜间降温运行

### 4.2 节能措施

| 措施 | 效果 |
|------|------|
| 冷凝回收 | 效率提高10～15% |
| 烟气余热回收 | 效率提高3～8% |
| 气候补偿 | 节能10～20% |
| 变频调节 | 节电20～40% |
| 定期维护 | 保持效率，延长寿命 |
